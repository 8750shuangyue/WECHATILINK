### 2.1 `common.js`（552 行）

新增 `window.UI`：

- `UI.me()`：memoized `/api/auth/me`，返回完整信封；失败清缓存。
- `UI.requireLogin(cb)`：沿用 `cb(data)` 回调契约。

- `UI.setBusy`：禁用按钮、`aria-busy`、可选替换文案、恢复原文。
- `UI.escapeHtml` / `UI.escapeAttr`。
- `UI.sw`：`register/getRegistration/applicationServerKey/payload`。

旧全局函数 `showToast`、`toast`、`apiFetch`、`apiJson`、`requireLogin`、`logout`、`renderSourcesBlock`、`renderAnswerWithCitations`、`compressImage` 保留为兼容层，页面内联 `onclick` 不受影响。

`shell.js` 删除独立的 `/api/auth/me` 请求，用户名统一由 `UI.me()` 填充，避免 shell + 页面重复请求。

## 四、Service Worker 根作用域

### 4.1 后端

`SecurityHeadersFilter` 对精确路径 `/js/service-worker.js` 增加：

```text
Service-Worker-Allowed: /
Cache-Control: no-cache, must-revalidate
```

其他 `/js/*` 不返回该头。

### 4.2 前端

- 注册改为 `register('/js/service-worker.js', { scope: '/' })`；捕获 `SecurityError` 降级到默认 `/js/`，兼容滚动发布。
- `UI.sw.getRegistration()` 统一处理注册与旧注册清理；`push.js`、`home.html` 不再各自注册。
- VAPID 公钥集中到 `common.js` 的 `UI.sw`。
- 旧 `/js/` 注册迁移：先在新根注册上订阅并保存新 endpoint，成功后再取消旧订阅、删除旧 endpoint、注销旧注册；旧订阅查询加 3 秒超时，清理逻辑后台执行，不阻塞页面。
- 旧注册查询/迁移失败时保留旧注册，下次页面加载重试，避免推送中断。

### 4.3 验证

- `SecurityHeadersFilterTest` 新增 3 个用例，`4/4` 通过。
- 本地运行 `curl -I /js/service-worker.js` 返回 `Service-Worker-Allowed: /`，`Cache-Control: no-cache, must-revalidate`。
- 浏览器 headless 验证：根 scope 注册成功，`navigator.serviceWorker.ready` 可 resolve。
- 旧 `/js/` 注册迁移验证：最终只剩根 scope 注册。

## 五、顺带修复

### 5.1 未知页面 500 → 404

验证页面状态时发现，`@RestControllerAdvice` 的兜底 `Exception` 处理把 `NoResourceFoundException` 映射成 500。已在 `GlobalApiExceptionHandler` 增加：

- `NoResourceFoundException` → HTTP 404 + `{code:404,message:"资源不存在"}`。

已下线页面 `/shop`、`/shop-publish`、`/briefing`、`/gallery`、`/disease.html`、`/timeline.html`、`/inventory.html` 现在均返回 404。
