## 三、交付内容

### 3.1 共享应用壳

- 新增 `src/main/resources/static/js/shell.js`：在 `<body>` 第一行以阻塞脚本注入左侧栏，7 个导航项单一来源，按 `location.pathname` 高亮当前页；移动端由 CSS 变为可横向滑动的顶条。
- 重写 `css/ui.css`：唯一令牌源（画布、文字、线条、品牌色、圆角、间距、字号），并承载侧栏、页头、按钮、表单、卡片、KPI、通知条、页脚与响应式规则。
- 新增 `css/pages.css`：页面专属结构（首页今天条与主入口、护理 hero/上传/档案、提醒卡、知识库文档卡、统计排行与柱状图、对话气泡与输入区）。
- 删除 `css/soft.css`、`css/chat.css`（原先是事后覆盖层，造成冷绿灰与暖米色两套画布并存）。

### 3.2 页面改造

| 页面 | 主要变化 |
| --- | --- |
| 概览 | 删除内联侧栏，改用 `shell.js`；改为「今天待办 → 护理/对话主入口 → 四个轻入口」；修复 `.ui-main` 宽屏左挤 |
| 护理助手 | 植物/宠物切换改为页头分段控件；上传区、问答、档案、记录、素材统一卡片；删除 220 行内联样式 |
| AI 对话 | 样式表从 `<body>` 末尾移到 `<head>`（消除闪屏）；会话工具栏移到右侧，避免双左栏；高度按视口计算 |
| 护理提醒 | 三个统计卡改用 `.ui-kpis`；新建/列表两栏；删除 97 行内联样式 |
| 养护社区 | 删除 68 行覆盖层，旧组件变量桥接到新令牌；修复 `.modal` 被错误套上遮罩背景的问题；补 `/community` 路由 |
| 知识库 | 从纯内联样式迁到统一系统；文档卡统一 |
| 数据概览 | 同上；统计卡改用 `.ui-kpis`，排行/趋势样式迁入 `pages.css` |

### 3.3 首页行动优先

- 「今天」条：待办提醒数量 + 最近一条 `PENDING` 提醒（今天/明天/已到期）+ 植物/宠物档案数。
- 主入口：护理助手 2/3、AI 对话 1/3。
- 轻入口：提醒、社区、知识库、数据概览。
- 数据源：`/api/ai/care/reminders/pending`、`/api/ai/care/reminders`、`/api/care/targets/PLANT|PET`。

### 3.4 附带修复

- `prefers-reduced-motion` 下社区帖子永远不可见：原规则 `animation:none` 会让依赖 `animation-fill-mode` 的卡片停在 `opacity:0`，改为缩短动画时长。
- 新增 `/community` 路由，导航统一使用干净路径；`/community.html` 仍可直接访问。
- 推送深链由 `/home.html` 改为 `/home`。
- 备案页脚改为整块居中。
- 归档页脚（`common.js`）优先注入主内容列，避免掉到侧栏下方。

### 3.5 同期附带修复（非阶段 5 范围）
