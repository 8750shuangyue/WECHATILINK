### 7.3 告警与 uptime

- 新增 `scripts/healthcheck.sh`：检查本机 `/login`、管理端口 `health`、公网 HTTPS、systemd 状态。
- 失败写 `/opt/ilink/healthcheck.log`；配置 `ALERT_WEBHOOK_URL` 后推送企业微信/钉钉。
- systemd 单元模板：`scripts/systemd/ilink-healthcheck.{service,timer}`，默认每 5 分钟。
- 安装步骤：
  ```bash
  sudo cp scripts/healthcheck.sh /usr/local/bin/ilink-healthcheck.sh
  sudo chmod +x /usr/local/bin/ilink-healthcheck.sh
  sudo cp scripts/systemd/ilink-healthcheck.service /etc/systemd/system/
  sudo cp scripts/systemd/ilink-healthcheck.timer /etc/systemd/system/
  sudo cp scripts/systemd/ilink-healthcheck.default /etc/default/ilink-healthcheck
  sudo systemctl daemon-reload
  sudo systemctl enable --now ilink-healthcheck.timer
  ```
