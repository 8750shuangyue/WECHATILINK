## 二、生产链路

```text
浏览器
  |
  | HTTPS 443
  v
Nginx（sekaipetplant.com）
  |
  | 仅本机代理 http://127.0.0.1:8080
  v
Spring Boot（ilink.service）
  |
  +-- MySQL 127.0.0.1:3306
  +-- /opt/ilink/uploads
  +-- /opt/ilink/rag_knowledge.sqlite
```

公网端口基线：

- `22`：保留 SSH，建议继续限制来源 IP。
- `80`：仅用于跳转 HTTPS 和证书续期校验。
- `443`：正式 Web 入口。
- `8080`：仅监听 `127.0.0.1`，公网访问已关闭。
- `3306`：不对公网开放。

## 四、日常检查

Nginx 与证书：

```bash
sudo nginx -t

```

应用与域名：

```bash
systemctl is-active ilink
ss -ltnp | grep ':8080'
curl -I http://127.0.0.1:8080/
curl -I https://sekaipetplant.com
curl -I https://www.sekaipetplant.com
tail -n 50 /opt/ilink/app.log
```

正常状态：

- `ilink` 为 `active`。
- `8080` 只监听 `127.0.0.1`。
- 本地探针、主域名和 `www` 域名均返回 HTTP `200`。
- 公网 `http://101.37.254.73:8080` 应连接超时。

## 五、剩余事项

以下事项不影响当前域名访问，但仍需继续处理：

1. 外部服务旧密钥轮换。用户当前决定暂缓，但这仍是公开上线后的 P0 安全事项。
2. 在 Nginx 或云侧增加按 IP / 路径的全局限流、反滥用和必要的 WAF。
3. 公安备案审核完成后，补充公安备案号及页面展示。
4. 增加关键操作审计、依赖漏洞扫描、监控告警和备份恢复演练。
5. 后续版本发布继续沿用“上传 `.new`、备份、替换、重启、等待约 60 秒、验证 HTTPS”的流程。
