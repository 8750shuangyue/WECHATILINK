# 浏览器端与微信端功能介绍

> 覆盖平台：浏览器 Web（`localhost:8080` / 阿里云公网）与微信 ILink 个人号机器人。

---

## 一、浏览器端（Web）功能

### 1. 账号与入口

- **注册 / 登录 / 退出**：BCrypt 加密 + 会话管理，登录后进入智能首页
- **Liquid Glass 落地页**：登录前展示（玻璃拟态风格），已登录用户访问根路径自动跳转首页

### 2. 智能首页（/home）

- **个人问候**：按时间段问候 + 显示当前日期
- **数据总览卡**：植物档案数、宠物档案数、待办提醒数、库存用品数（实时接口统计）
- **核心系统入口**：AI 护理中心、微信对话
- **特色功能入口**：病害诊断、智能库存、成长时间线、护理问答、养护社区、商城
- **浏览器推送开关**：WebPush 一键订阅/取消

### 3. AI 对话（/chat）

- 基于 **Spring AI** 对话引擎，支持 `/api/ai/chat` 与 `/api/ai/chat-with-tools`
- 内置 **24 个 @Tool 工具**：护理提醒创建/完成/查询、宠物与植物安全问答、症状分诊、用药记录、图片对比、护理计划生成、天气预警、附近服务、联网搜索、生图/图片分析等
- 展示工具调用历史（成功/失败、耗时、参数）

### 4. 智能护理（/care）

- **拍照识别**：上传植物/宠物照片 → qwen-vl 视觉识别品种与健康状态 → LLM 生成护理建议
- **护理对象管理**：植物/宠物档案的新建、查询、删除
- **护理记录**：喂药/浇水等记录查看与新增
- **护理问答**：结合识别历史与知识库的 AI 问答

### 5. 病害诊断（/disease.html）

- 上传叶片/皮肤照片，AI 识别病虫害并给出治疗方案
- 查看历史诊断记录

### 6. 商城（/shop、/shop-publish）

- 商品列表：搜索、分类筛选、价格/库存展示、分页
- 商品详情弹窗：图片、描述、库存、分类标签
- 商品发布：标题、描述、价格、库存、分类、图片
- 数据统计：商品总数、分类数等概览

### 7. 库存管理（/inventory.html）

- 用品台账：新增、编辑、删除
- 消耗登记：按用量扣减库存
- **低库存提醒**：低于阈值自动标记，提供告警列表

### 8. 社区（/community.html）

- 帖子发布、列表分页、详情页
- 评论（支持回复）、点赞、标签云与热门标签

### 9. 成长时间线（/timeline.html）

- 照片/里程碑/护理记录三类时间线条目
- **AI 里程碑识别**：自动从照片/记录中识别成长节点
- 图片标注：对时间线图片进行 AI 描述标注

### 10. 浏览器推送（WebPush）

- Service Worker 订阅/退订
- 接收护理提醒、测试推送（应用层已具备，服务器端因 BouncyCastle 密钥问题暂禁用，属已知待修复项）

### 技术特点

- 12 个静态页面，无构建工具，直接 fetch REST API
- 移动端响应式适配、现代视觉设计（渐变、玻璃拟态、动效）
- 与微信端共用同一套 AI 能力与数据库

## 二、微信端（ILink 个人号）功能

### 1. 机器人接入

- 扫码登录微信个人号机器人，登录态持久化（`login_state.json`），重启免重复扫码
- 每 3 秒轮询消息，支持文本 / 图片 / 语音 / 文件四种消息

### 2. 多模态消息处理

| 消息类型 | 处理链路 |
|---|---|
| 文本 | 直接进入 Agent 对话（DeepSeek + 8 个 BaseTool 工具） |
| 图片 | qwen-vl 预识别 → 结合文字指令分析/编辑/生成 |
| 语音 | ffmpeg 转 WAV → DashScope ASR 转文字 → 进入对话 |
| 文件 | PDF/Word/TXT 解析 → 基于文件内容问答（analyzeFile） |

### 3. Agent 工具调用

- 内置 **8 个工具**：天气、联网搜索、文生图、图片编辑、图片分析、文件分析、语音合成、附近服务
- **多工具串联**：例如"查杭州天气 → 生成西湖风景图 → 语音朗读结果"
- **三层兜底**：LLM 未调工具时，依次尝试直接调用 → 自然语言工具解析 → 关键词强制调用
- 工具并发执行（线程池 ≤4、单工具 15 秒超时），最多 5 轮推理

### 4. 地图导航（附近服务）

- **高德地图集成**（`AmapService`）：地址地理编码（geocode）、POI 搜索（searchNearbyPois）、网页导航链接（`uri.amap.com/navigation`）、地图标记
- **`searchNearbyService` 工具**：支持 7 类服务——宠物医院 / 24 小时急诊 / 诊所 / 植物医院 / 园艺店 / 宠物店 / 美容，输入位置即可查询
- **结果卡片**：店名、距离、地址、电话、**导航直达链接**（"🚗 导航直达：点我打开高德地图 → URL"）、预约挂号信息
- **导航链接强制保留**：工具描述要求 LLM 原样输出导航 URL，不省略、不改写
- 示例：发送"帮我找一下杭州余杭区附近的宠物医院"→ 返回附近医院卡片 + 一键导航

### 5. 交互体验

- **进度提示**：处理超过 10 秒先发送"正在努力生成中"
- **多形态回复**：文字、图片、语音消息（语音由讯飞 TTS 合成）
- 回复内容自动截断保护（公众号渠道 600 字）

### 技术特点

- 自研 Agent 循环（`AgentService`），与 Web 端 Spring AI 通路互补
- 个人号直连，无小程序/公众号审核门槛，适合快速验证与日常使用
- 登录态文件与运行时数据均不进 Git 仓库

## 三、双端能力对比

| 维度 | 浏览器端 | 微信端 |
|---|---|---|
| 对话引擎 | Spring AI（24 个 @Tool） | 自研 AgentService（8 个 BaseTool） |
| 输入类型 | 文字、图片上传 | 文字、图片、语音、文件 |
| 视觉识别 | qwen-vl（护理/病害识别） | qwen-vl（图片预识别） |
| 语音能力 | — | ASR 语音输入 + TTS 语音回复 |
| 文件处理 | 上传解析 | 微信文件消息解析 |
| 提醒触达 | WebPush 浏览器推送 | 微信消息直接送达 |
| 业务模块 | 首页/护理/商城/库存/社区/时间线/病害/简报接口 | 护理问答、提醒、天气/生图/搜索等工具 |
| 推送通知 | 订阅式 WebPush | 微信消息（实时性强） |

---

## 四、双端协同

- **同一套 AI 能力**：微信端自研 Agent 与 Web 端 Spring AI 共用 DeepSeek、qwen 系列模型、向量知识库与 MySQL 业务库
- **同一份数据**：护理档案、对话历史、向量记忆跨端共享
- **互补场景**：微信端承担"随手拍照、语音提问、轻量触达"，Web 端承担"复杂管理、浏览消费、深度配置"
