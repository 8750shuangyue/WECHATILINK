# Web 端功能介绍

> 覆盖平台：浏览器 Web（`localhost:8080` / 阿里云公网 `101.37.254.73:8080`）。
> 微信 ILink / 公众号接入已于 2026-08-15 移除，项目为纯 Web 端。

---

## 一、账号与入口

### 1. 落地页（`/` → index.html）

- Liquid Glass 玻璃拟态风格落地页，展示品牌与三大能力（AI 识别 / 智能提醒 / AI 对话）
- 已登录用户访问根路径自动跳转 `/home`；未登录用户看到“登录 / 注册”入口

### 2. 注册 / 登录 / 退出

- 注册、登录、退出接口：`/api/auth/register` `/api/auth/login` `/api/auth/logout` `/api/auth/me`
- 密码 BCrypt 加密存储，登录后建立 Session 会话
- 前端守卫：`guard.js` + `common.js` 统一处理登录态检查与 401 跳转

## 二、智能首页（/home）

- **个人问候**：按时间段问候 + 当前日期
- **数据总览卡**：植物档案数、宠物档案数、待办提醒数、库存用品数（实时接口统计）
- **核心系统入口**：PetPlant 护理中心、AI 对话
- **特色功能入口**：病害诊断、智能库存、成长时间线、护理问答、养护社区、商城、提醒、简报、知识库
- **浏览器推送开关**：WebPush 一键订阅/取消

## 三、AI 对话（/chat）

- 对话接口：`/api/ai/chat`（普通）、`/api/ai/chat/stream`（**SSE 流式打字机输出**）、`/api/ai/chat-with-tools`（工具对话）
- 内置 **68 个 Spring AI @Tool 工具**：护理提醒创建/完成/查询、宠物与植物安全问答、症状分诊、用药记录、图片对比、护理计划生成、天气预警、附近服务、联网搜索、生图/图片分析等
- 展示工具调用历史（成功/失败、耗时、参数）
- 记忆与 RAG：对话历史 + 向量检索自动注入，模型“记得住”上下文

## 四、智能护理（/care）

- **拍照识别**：上传植物/宠物照片 → qwen-vl 视觉识别品种与健康状态 → LLM 生成护理建议（`/api/care/identify`）
- **护理对象管理**：植物/宠物档案的新建、查询、删除（按用户隔离）
- **护理记录**：喂药/浇水等记录查看与新增（归属校验）
- **护理问答**：结合识别历史与知识库的 AI 问答（`/api/care/qa`）

## 五、病害诊断（/disease）

- 上传叶片/皮肤照片，AI 识别病虫害并给出治疗方案
- 查看历史诊断记录

## 六、护理提醒（/reminders）

- 提醒创建：浇水/施肥/驱虫/疫苗/喂药，支持每日/每周/每月重复
- 到期自动推送：`CareReminderService` 每分钟扫描，统一走 **WebPush 浏览器推送**
- 待办数字：首页数据卡实时显示 PENDING 数量

## 七、知识库（/kb）

- 上传文档（PDF/Word/TXT）→ 自动分块 → Embedding 向量化 → SQLite 向量库入库
- 对话时自动检索增强回答（RAG）
- 知识条目列表查看与删除

## 八、每日简报（/briefing）

- 简报生成：天气 + 护理提醒 + LLM 汇总
- 每天 8 点定时生成并 WebPush 推送给订阅用户

## 九、商城（/shop、/shop-publish）

- 商品列表：搜索、分类筛选、价格/库存展示、分页
- 商品详情弹窗：图片、描述、库存、分类标签
- 商品发布：标题、描述、价格、库存、分类、图片
- 数据统计：商品总数、分类数等概览

## 十、库存管理（/inventory）

- 用品台账：新增、编辑、删除
- 消耗登记：按用量扣减库存
- **低库存提醒**：低于阈值自动标记，提供告警列表

## 十一、社区（/community）

- 帖子发布、列表分页、详情页
- 评论（支持回复）、点赞、标签云与热门标签

## 十二、成长时间线（/timeline）

- 照片/里程碑/护理记录三类时间线条目
- **AI 里程碑识别**：自动从照片/记录中识别成长节点
- 图片标注：对时间线图片进行 AI 描述标注

## 十三、浏览器推送（WebPush）

- Service Worker 订阅/退订（`push.js`）
- 接收护理提醒、每日简报
- VAPID 密钥已修复（公钥/私钥同步），订阅后即可收到推送

## 十四、接口鉴权与安全

- `WebAuthInterceptor` 拦截 `/api/**`、`/uploads/**`，除白名单（登录/注册/me/OPTIONS）外均需登录
- 未登录统一返回 401 + `{"code":500,"message":"未登录"}`
- 数据隔离：宠物/植物档案、护理记录、提醒均按 `user_id` 归属校验，防止越权

## 十五、数据概览（/stats）

- **平台统计**：注册用户、对话消息、工具调用、知识库条目、护理对象、待办提醒、社区帖子、商城商品
- **工具调用排行 Top10**：调用次数 + 成功率 + 平均耗时（来自 `tool_call_logs` 埋点）
- **近 7 天对话趋势**：按天统计消息量柱状图
- 首页“数据概览”卡片直达；数据实时来自 `/api/stats/*`

## 技术特点

- 16 个静态页面（index/login/register/home/chat/care/disease/shop/shop-publish/community/inventory/timeline/reminders/briefing/kb/stats），无前端构建工具，直接 fetch REST API
- 移动端响应式适配、现代视觉设计（渐变、玻璃拟态、动效）
- 与后端共用同一套 AI 能力、记忆 RAG 与 MySQL 业务库
