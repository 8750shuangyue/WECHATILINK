# 对犬有风险的家庭常见植物清单

## 高风险植物

以下常见家庭绿植对犬有毒性风险，误食可能引起呕吐、腹泻、流涎、口腔灼痛，严重时危及生命：

1. **百合**（对猫剧毒，对犬也可能刺激）：摄入任何部位可导致急性肾损伤。
2. **绿萝**：含草酸钙结晶，误食引起口腔与消化道刺激、呕吐、流涎。
3. **龟背竹、滴水观音（海芋）**：同样含草酸钙结晶，刺激黏膜。
4. **一品红**：乳汁刺激肠胃，误食引起呕吐。
5. **郁金香、水仙**：鳞茎毒性强，可致呕吐、腹泻，严重时抽搐。
6. **夹竹桃**：强心苷类毒素，误食可致心律失常，极度危险。
7. **芦荟**：皂苷成分，可刺激肠道致呕吐腹泻。
8. **常春藤**：皂苷类毒素，误食致呕吐、腹痛。

## 预防与处置

1. **避免犬误食**：将有毒植物放置于犬无法触及的位置，或不在犬活动区域种植。
2. 出现啃咬迹象时立即隔离犬只并清理残留叶片。
3. **误食就医**：一旦确认犬误食上述植物并出现呕吐、流涎、共济失调等症状，应立即就近送兽医急诊，勿自行催吐或用药，保存植物样本供兽医辨识。
