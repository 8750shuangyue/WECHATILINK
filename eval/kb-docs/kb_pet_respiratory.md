# 宠物呼吸道症状处理指南

## 狗打喷嚏、流清鼻涕

狗出现打喷嚏、流清鼻涕等轻度呼吸道症状，先不要急着下结论。

处理建议：

1. **轻度症状先观察**：精神、食欲正常的轻度打喷嚏流鼻涕，可先居家观察 1-2 天，注意保暖、减少外出受凉。
2. **出现警示信号需就医**：若出现精神萎靡、食欲下降、发热（体温升高）、脓性鼻涕、咳嗽加重等情况，应尽快就医排查传染性疾病。
3. **禁止人药兽用**：不能自行给狗喂人用感冒药，很多人类感冒药（如含对乙酰氨基酚成分）对犬有毒性。

## 就医判断

- 单纯清涕、偶发喷嚏多为环境刺激或轻微着凉。
- 持续多天症状、伴随精神差或发热，需就医做血检与筛查，不要在家拖延。
