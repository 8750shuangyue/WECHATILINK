# 幼猫疫苗接种时间表

## 核心疫苗接种程序

幼猫通常在 8 周龄（2 月龄）后开始接种，需**到龄接种**并按程序**完成加强针**。

1. **8-9 周龄**：第 1 针猫三联疫苗（猫瘟、杯状病毒、疱疹病毒）。
2. **12-13 周龄**：第 2 针猫三联（与首针间隔 3-4 周）。
3. **16 周龄或以上**：第 3 针猫三联（部分方案为第 2 针后复查加强）。
4. **狂犬疫苗**：满 3 月龄后接种，按当地法规与疫苗品牌规定执行。

## 完成程序后的管理

- 首年免疫程序完成后，进入成年加强阶段：按兽医与疫苗品牌建议，通常每 1-3 年加强一次猫三联。
- 每次接种前由兽医进行健康检查，接种后留观 15-30 分钟。
- 未完成全程免疫前，避免带幼猫外出或接触流浪猫/密集场所。

## 提示

- 具体月龄与针数以疫苗厂商说明书和当地兽防部门规定为准，回答时须与知识库一致。
