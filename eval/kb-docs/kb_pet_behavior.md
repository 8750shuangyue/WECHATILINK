# 宠物行为与应激处理指南

## 狗害怕鞭炮/巨响

狗狗对鞭炮、雷声等巨响产生恐惧是常见行为问题。

处理建议：

1. **减少刺激源、提供安全角落**：拉上窗帘、播放白噪音或电视声掩盖响声，为狗狗准备一个安静安全的小空间（笼子或角落铺软垫），让它有地方躲避。
2. **不要强行安抚或惩罚**：狗狗害怕时不要强行抱着、按住它"安慰"，这会让它感到被束缚更紧张；更不要打骂惩罚，会加重恐惧。保持淡定，正常做自己的事，让狗狗有安全感。
3. **逐步脱敏**：平时可播放鞭炮音录音，从低音量开始配合零食奖励，逐步提高音量做脱敏训练。
4. **持续严重可咨询兽医**：若极端恐惧、有自伤/破坏行为，可咨询兽医行为科，评估是否需要抗焦虑药物或行为矫正。

## 应激应对通则

- 猫应激（新环境、来客、搬家）表现为躲藏、拒食、过度舔毛，应提供隐蔽空间、不强行抱出。
- 应激期保持环境和作息稳定，减少变化，必要时使用费洛蒙类安抚产品。
