# 宠物腹泻处理指南

## 轻度腹泻处理

1. **短期禁食观察**：轻度腹泻可短暂禁食 6-12 小时（幼宠和老年宠遵医嘱），让肠胃休息，之后给予易消化的清淡食物（如白水煮鸡胸肉拌米饭）。
2. **保证饮水、补充电解质**：腹泻易脱水，要保证充足清洁饮水，可补充宠物专用电解质水维持体液平衡。
3. 观察精神状态和排便情况，记录腹泻次数、粪便性状和有无出血。

## 就医信号

出现以下情况应及时就医：

- **持续或带血**：腹泻持续超过 24-48 小时，或粪便带血、呈黑便。
- 伴随呕吐、精神萎靡、发热、食欲废绝。
- 幼宠、老年宠或体弱宠物出现腹泻，应更早就医。
- **不要自行给人用止泻药**：人用止泻药成分对宠物可能有毒，且强行止泻可能掩盖病因。
- **不要连续多日在家硬扛**：多日腹泻不止会严重脱水和电解质紊乱，应尽快就医。

## 就医前准备

- 携带粪便样本（2 小时内为佳）便于化验排查寄生虫、细菌感染等。
