# 月季黑斑病｜病害基础处理

- 文献依据：UC IPM月季病害管理文献；苏州市园林植保月季病害技术文档
  通风不良、叶面长时间潮湿是月季黑斑病常见的诱发条件，病菌借雨水、溅水传播。发现叶片出现黑色斑点、叶缘黄化，应及时摘除并清除病叶、病枝，减少侵染源；配合改善通风、避免叶面长时间带水、浇水不溅叶等基础管理。病害较重时可选用合规低毒杀菌剂按规定浓度喷施，按说明轮换使用以减缓抗性。
1. 禁止感染黑斑病后放任不管、不做任何处理；
2. 禁止直接使用高浓度农药盲目喷施。

处理方法：

1. 及时摘除并清理病叶、病枝，集中带离销毁，减少病菌再侵染源；
2. 改善环境：保证充足光照与通风，避免密植、避免叶面长时间潮湿，浇水不溅湿叶片；
3. 选用抗病品种或增强植株长势，从源头降低发病；
4. 病害较重时，按说明使用合规低毒预防性杀菌剂（如百菌清、铜制剂、腈菌唑、印楝油等）按规定浓度、7~14天间隔喷施，并轮换药剂以减缓抗性。

处理方法科学依据：

1. 黑斑病由真菌 Diplocarpon rosae 引起，通风不良、叶面潮湿利于其传播；摘除病叶、改善通风是综合防治基础（来源25，月季黑斑病防治）。
2. 栽培管理（充足光照、通风、避免叶面滞水）配合低毒预防性杀菌剂，是黑斑病有效综合防治策略（来源26，月季黑斑病管理）。
3. 常规杀菌剂如百菌清、铜制剂、腈菌唑等可有效控制黑斑病，但需按规定浓度与间隔施用，避免盲目高浓度用药（来源25，月季黑斑病药剂防治）。
