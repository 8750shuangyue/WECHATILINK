# 宠物中毒急救指南

## 犬误食巧克力

巧克力对犬有毒性，主要来自可可碱和咖啡因，黑巧克力、烘焙巧克力含量最高。

处理步骤：

1. **记录摄入量和时间**：立即记录误食的巧克力种类、大约克数和摄入时间，供兽医评估。
2. **建议及时就医**：根据摄入量和犬体重判断风险，多数情况建议尽快就医评估，必要时催吐或给活性炭处理。
3. **禁止在家自行催吐**：不要在家用盐、双氧水等自行催吐，操作不当会误吸或损伤食道。
4. **不能等待观察**：出现兴奋、心跳加速、震颤、呕吐、抽搐等症状属于中毒表现，应紧急就医，不要"观察24小时再说"。

## 常见犬猫中毒物

- 巧克力、洋葱大蒜、葡萄、木糖醇、部分人类药物（对乙酰氨基酚、布洛芬）对宠物有毒性。
- 误食人用药物、家用化学品时，应尽快带上包装/说明书就医。

## 通用急救原则

- 误食毒物后优先联系兽医或宠物急救中心，说明毒物与剂量。
- 不要自行催吐，不要自行用药，尽快送医。
