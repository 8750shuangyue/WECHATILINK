# 对宠物有毒的常见家养植物清单

## 高风险植物

- **百合属（百合、萱草等）**：对猫有较强毒性，猫误食花粉或啃食叶片后可能引发急性肾衰竭，即使少量摄入也危险。
- **绿萝、龟背竹、滴水观音（天南星科）**：汁液含草酸钙针晶，猫咪和狗啃咬后口腔、舌头会剧烈刺痛、流涎、呕吐，需避免接触和误食。
- **夹竹桃**：全株有毒，误食可致心律异常。
- **郁金香、水仙**：鳞茎有毒，误食可致呕吐腹泻。
- **杜鹃花、一品红**：误食可致消化道刺激症状。

## 处置与预防

- 家中养猫养狗时，尽量选择对宠物无毒的植物，或将有毒植物放在宠物无法触及的位置。
- 发现宠物误食有毒植物后，应尽快送医，不要简单以"养着没事"的心态对待，不要自行在家催吐。
- 就医前记录误食的植物种类、大约数量和摄入时间，便于兽医判断处理。
