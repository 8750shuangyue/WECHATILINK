# 植物病害与虫害防治指南

## 月季黑斑病

黑斑病是月季常见病害，表现为叶片出现黑褐色圆斑，严重时叶片大量脱落。

处理步骤：

1. **清除并销毁病叶**：及时摘除并清理掉落的病叶，避免病原扩散，不可随意堆放在盆土表面。
2. **保持通风、避免叶片积水**：改善通风条件，浇水时避免叶片长时间湿润，尽量浇在土面。
3. **规范使用杀菌剂**：使用针对性的杀菌剂（如含苯醚甲环唑、代森锰锌成分药剂），按说明安全使用，注意稀释浓度与安全间隔期。
4. **严重时求助专业**：若病情蔓延无法控制，建议咨询园艺或植保专业人员，不要自行加大药量。

## 多肉黑腐病

黑腐病多见于夏季高温高湿环境，由真菌感染引起，茎部发软、发黑。

急救处理：

1. **及时切除腐烂部位**：尽早用消毒刀具切除所有腐烂组织，切到健康组织为止，越早处理挽救成功率越高，切勿拖到整株腐烂。
2. **伤口晾干或消毒后重新种植**：切口涂抹多菌灵或晾干 2-3 天形成愈合后再上盆。
3. **通风控水降低复发**：后续保持良好通风、控制浇水，避免再次感染。不要使用成分不明的药水。

## 绿萝常见害虫

- 常见害虫有红蜘蛛（叶背结网、叶面有黄白斑点）、蚜虫、介壳虫等。
- 优先物理防治：摘除虫叶、清水冲洗、湿布擦拭叶片。
- 虫害严重时规范使用低毒杀虫剂，按说明稀释，注意通风，避免药害。不要使用未经验证的高毒农药。
