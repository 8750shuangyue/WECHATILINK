# 宠物呕吐处理指南

## 区分毛球与疾病原因

猫呕吐需先区分原因：

- **毛球呕吐**：呕出毛球或少量泡沫、黏液，精神食欲正常，属于正常排毛现象，可定期喂化毛膏或猫草预防。
- **疾病性呕吐**：频繁呕吐、呕吐物带血/胆汁/异物、伴随精神萎靡、食欲废绝、腹泻等，提示胃肠道疾病、寄生虫、异物或器官问题。

## 处理建议

1. **观察食欲和精神状态**：偶发一次呕吐且精神食欲正常，可禁食少量观察；若频繁呕吐或持续呕吐需就医。
2. **不要自行用药**：不能随便使用人用止吐药，剂量和安全性无法保证。
3. **及时就医**：一天内呕吐两次以上、持续呕吐、呕吐物异常或伴随其他症状，应带宠物就医，不要拖延。

## 就医前注意事项

- 记录呕吐频率、呕吐物性状、发病时间，供兽医参考。
- 就医前可短暂禁食 6-12 小时让胃肠道休息，但幼猫和老年猫禁食需谨慎，遵兽医建议。
