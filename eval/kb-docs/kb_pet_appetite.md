# 宠物厌食风险处理指南

## 猫厌食的风险

猫长时间不进食（超过 24-48 小时）风险很高，可能诱发**脂肪肝（肝脂沉积症）**，是猫常见且危险的继发问题，因此猫厌食不能掉以轻心。

## 处理建议

1. **观察精神、饮水和大小便**：先观察猫咪精神状态、饮水情况和大小便是否正常，排查应激、换粮、环境变化等因素。
2. **尽快就医**：若连续 1-2 天不进食或进食明显减少，建议尽快就医检查，排查胃肠道疾病、肾脏问题、口腔疼痛等原因。
3. **不要硬灌食物**：强行灌食可能导致误吸和应激，且若是疾病性厌食，灌食无法解决问题。
4. **不要继续观望拖延**：猫与狗不同，数日不进食就可能出现严重代谢问题，主人不应"再等等看"。

## 就医前准备

- 记录厌食开始时间、伴随症状（呕吐、腹泻、精神变化）、近期饮食变化，供兽医参考。
