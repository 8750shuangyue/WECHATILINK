# 幼猫喂养指南

## 猫粮选择

1. 幼猫应选择**幼猫专用全价猫粮**或离乳期奶糕/幼猫粮，这类猫粮蛋白质、脂肪、钙磷比例符合幼猫生长发育需求。
2. 幼猫粮通常分为奶糕（1-4 月龄）与幼猫粮（4-12 月龄）两个阶段，按月龄对应选择。
3. 不应让幼猫长期食用成猫粮，成猫粮营养密度不足以支持幼猫骨骼与肌肉发育。

## 喂食频率：少食多餐

1. **1-2 月龄**：每日喂食 4-5 次，少量多次，配合冲泡羊奶粉或离乳食品。
2. **3-6 月龄**：每日喂食 3-4 次。
3. **6-12 月龄**：逐渐过渡到每日 2-3 次。
4. 提供充足的清洁饮水，食器每日清洗。

## 注意事项

- 忌喂人食、牛奶（乳糖不耐受易腹泻）。
- 换粮需 7 天左右逐步过渡，避免突然更换引起肠胃不适。
