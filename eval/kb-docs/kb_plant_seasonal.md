# 植物季节性养护指南

## 君子兰夹箭处理

君子兰夹箭指花箭抽不出来卡在叶丛中，常见诱因是温差不足、养分和光照不当。

处理措施：

1. **温差刺激**：通过降低夜间温度（如夜间 10-15℃，白天 20-25℃），利用昼夜温差刺激花箭抽出。
2. **补充磷钾肥**：花期前后补充磷钾肥促进抽箭，减少氮肥。
3. **调整光照温度环境**：保证充足散射光与适宜温度，避免光照过强或过暗。
4. 严禁暴力拔箭，强行拉扯会损伤植株；花箭抽出后保持温度稳定防夹箭。

## 栀子花黄叶处理

栀子花喜酸性土壤，在碱性土壤中易出现缺铁性黄叶。

处理措施：

1. **判断缺铁黄叶**：新叶叶脉绿色、叶肉发黄多为缺铁，常见于盆土偏碱。
2. **调节土壤酸碱度**：适量施用硫酸亚铁或腐殖酸调节土壤 pH，改善黄叶。
3. 不要盲目大量使用硫酸亚铁，过量会伤根；应少量多次，观察叶片恢复情况。

## 冬季养护

- 冬季气温降低，植物进入半休眠状态，需减少浇水频率，保持土壤偏干，避免按夏季频率浇水导致积水烂根。
- 室内暖气房空气干燥时，可向叶片喷水保湿，但盆内控水。
- 温度保持在适宜范围（多数室内绿植 10℃ 以上），避免冷风直吹。
